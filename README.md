# Goal of the project

Create a programming language that can be easily used with only one hand. The objectif is to make code more accessible to every people.

## Why This Matters ?

Many developers face challenges due to repetitive strain injuries, disabilities, or limb differences, making traditional coding environments cumbersome or even painful to use. By rethinking how a programming language is structured—from syntax to tooling—this project aims to reduce physical strain and make coding more accessible.

Key Features
**Minimal Keystrokes**: The syntax is concise and optimized for fewer characters, reducing hand movement and fatigue.

**Customizable Input**: Supports integration with assistive devices (e.g., eye-tracking, voice commands, or adaptive keyboards).

**Ergonomic Design**: The language prioritizes logical clarity and simplicity, minimizing the need for complex shortcuts or awkward key combinations.

**Community-Driven**: Developed with feedback from developers with disabilities to ensure real-world usability.

## Why It’s Unique ?
While other projects focus on adapting existing tools, this language is built from the ground up with accessibility as its core principle. It’s not just about making coding possible—it’s about making it effortless and enjoyable for everyone.
